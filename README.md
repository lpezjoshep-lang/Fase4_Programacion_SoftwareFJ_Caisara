## Descripción del proyecto

Este proyecto consiste en el desarrollo de un sistema de gestión de clientes, servicios y reservas para la empresa ficticia Software FJ, utilizando el lenguaje de programación Python.

El programa aplica los principios de la programación orientada a objetos, incluyendo abstracción, herencia, polimorfismo y encapsulación. También incorpora validaciones y manejo de excepciones para controlar errores durante su ejecución.

## Funcionalidades principales

- Registro y validación de clientes.
- Gestión de servicios de reserva de salas, alquiler de equipos y asesorías especializadas.
- Creación, confirmación, procesamiento y cancelación de reservas.
- Cálculo de costos de los servicios.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores en el archivo `software_fj.log`.
- Simulación de operaciones correctas e incorrectas.

## Tecnologías utilizadas

- Python 3
- Visual Studio Code
- GitHub
- Biblioteca estándar de Python

## Instrucciones de ejecución

1. Descargar el archivo `main.py` del repositorio.
2. Abrirlo en Visual Studio Code.
3. Verificar que Python esté instalado.
4. Ejecutar el archivo mediante el comando `python main.py`.
5. Revisar los resultados en la terminal.
